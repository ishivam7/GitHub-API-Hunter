# GitHub API Hunter

# Project Description

A responsive web application that allows users to search GitHub profiles using the GitHub REST API. It displays user information and latest repositories.

# Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GitHub REST API
- Fetch API

# Features

- Search GitHub User
- User Profile
- Latest 5 Repositories
- Loading Spinner
- Error Handling
- Dark/Light Theme
- Search History
- Responsive Design

# Learning Outcomes

- API Integration
- Async/Await
- Fetch API
- DOM Manipulation
- Local Storage
- Responsive Web Design
