#  GitHub API Hunter

A modern and responsive web application that allows users to search for any GitHub profile using the GitHub REST API. It displays user details, latest repositories, and provides a clean UI with useful features like theme toggle and search history.

# Overview

GitHub API Hunter is a simple yet powerful web application built using **HTML, CSS, and JavaScript**. It fetches real-time data from the GitHub REST API and displays user profile information along with their latest repositories.

This project demonstrates API integration, asynchronous JavaScript, DOM manipulation, error handling, Local Storage, and responsive web design.

# Features

-  Search any GitHub user
-  View profile details
-  User avatar
-  Bio
-  Followers & Following
-  Public Repository Count
-  Account Creation Date
-  Latest 5 Repositories
-  Repository Stars
-  Fork Count
-  Programming Language
-  Visit GitHub Profile
-  Loading Spinner
-  Error Handling
-  Dark / Light Theme
-  Recent Search History (Local Storage)
-  Clear Search Input
-  Press Enter to Search
-  Fully Responsive Design
